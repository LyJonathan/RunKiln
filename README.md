# RunKiln

A lean coding agent for [RunInfra](https://runinfra.ai), with auto model routing. Fork of [Pi](https://github.com/earendil-works/pi) by Mario Zechner and contributors (see [NOTICE.md](NOTICE.md) and [docs/pi/](docs/pi/)).

**Install:** `npm i -g @runkiln/coding-agent` (Node 22.19+), then run `runkiln`.

**From source:** `git clone https://github.com/LyJonathan/RunKiln.git`, then `npm ci`, `npm run build`, `npm link -w @runkiln/coding-agent`.
